# NarrativeLine ユーザーガイド

NarrativeLineは、E2Rのデータセットを使って、できごとをタイムラインで編集するアプリケーションです。

E2Rの概要は、[E2R入門ガイド](https://github.com/sukoyaka-dopeness/e2r-spec/blob/main/docs/e2r-overview-ja.md)をご覧ください。

## このガイドで使う言葉

- データセット：1つの年表を構成する、できごと・エンティティ・関連付けなどをまとめたデータ
- できごと：年表に表示する、ある時点や期間に発生した出来事や活動
- エンティティ：できごとに関わる人物、組織、場所、物などの存在。たとえば、出来事が「月面着陸」なら、宇宙飛行士、NASA、月などがエンティティになります。
- 関連付け：できごととエンティティのつながり。関連付けることで、誰が、どの組織が、どの場所が、そのできごとに関係するかを記録できます。
- 拡張機能：日付やタイトルなど、E2Rの基本的なデータに追加できる情報

## データセットを始める

ホーム画面では、次の操作を選べます。

- データセットを新規作成
- E2R JSONを読み込む
- サンプルデータセットを開く
- 編集中のデータセットを開く

## データセットを読み込む

「E2R JSONを読み込む」からJSONファイルを選択します。

- 正常なデータセットはタイムライン画面で開きます。
- JSONの構文エラーや基本仕様の検証エラーがある場合は、読み込みが中止されます。
- 未知の拡張機能が含まれている場合は、警告を表示したうえで開きます。

## データセットのタイトル

作成している年表に名前を付けるには、タイムライン上部のタイトル欄に入力し、「タイトルを適用」を押します。
タイトルは、データセット内の拡張情報として記録され、書き出すJSONファイルにも含まれます。

技術情報：保存先は `extensions.metadata.title` です。

## できごとを編集する

タイムライン上でできごとを選択し、「編集」を押します。名前、説明、日付を編集できます。
保存するとタイムラインに戻ります。

「保存して関連エンティティを追加」を押すと、編集中の内容を保存して、既存のエンティティを選ぶ画面へ進みます。

## 画面遷移

NarrativeLineでは、タイムラインを中心に、できごととエンティティの編集画面を行き来します。

```text
ホーム
  ↓ データセットを開く
タイムライン
  ↓ できごとを追加／編集
できごとの詳細
  ├─ 保存 → タイムライン
  ├─ 関連エンティティを編集 → エンティティの詳細
  │                              └─ 保存／戻る → 元のできごとの詳細
  └─ 保存して関連エンティティを追加 → 関連エンティティを追加
                                       ├─ 既存エンティティを関連付ける → できごとの詳細
                                       └─ 新しいエンティティを作成
                                            ├─ 作成して関連付ける → できごとの詳細
                                            └─ 戻る → 関連エンティティを追加
```

画面下部では、左側に「戻る」、右側に保存・作成などの主操作が表示されます。削除は誤操作を避けるため、保存とは離れた危険操作領域にあります。

## エンティティを関連付ける

できごとの詳細画面で「保存して関連エンティティを追加」を押すと、関連エンティティを追加する画面が開きます。

- 既存のエンティティは「関連付けを追加」で選びます。
- 新規作成する場合は「新しいエンティティを作成」を押し、別画面で名前と説明を入力します。
- 「作成して関連付ける」を押すと、エンティティの作成と関連付けを同時に行います。
- 同じ名前のエンティティも作成できます。名前だけを理由に自動統合されることはありません。

関連付けると、必要なRelationが自動的に作成されます。

## エンティティを編集する

できごとの詳細画面で関連エンティティを選択し、「エンティティを編集」を押します。保存または戻る操作の後は、元のできごとの詳細画面へ戻り、対象の関連エンティティが表示されます。

関連付けの解除はエンティティ自体を削除しません。エンティティの削除は、エンティティの詳細画面にある独立した削除操作から行います。

## データセットを書き出す

タイムラインの「E2R JSONをエクスポート」を押します。

- タイトルがある場合：タイトルを使ったファイル名になります。
- タイトルがない場合：`e2r-dataset.e2r.json` になります。

エクスポート前にもデータセットの検証が行われます。

## 検証メッセージ

エラーはデータセットを開くことを妨げます。警告はデータセットを開けますが、内容を確認してください。
診断にはエラーコードとデータセット内の場所（JSONポインター）が表示されます。
